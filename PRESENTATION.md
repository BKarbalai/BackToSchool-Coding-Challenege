# Horizon — presenter notes (2-minute demo + full inventory)

## The one story to tell

**Plan → focus → land → review.** Everything feeds one loop: deadlines feed the
calendar, the calendar feeds time-blocks, focused sprints become flights, and
every landing banks miles, unlocks airports, and lands in travel history.

## 60-second demo path

1. Grades: drag a target slider — "what do I need on the final?"
2. Deadlines: tick one — confetti, panic meter relaxes.
3. Calendar: click a day — agenda + day planner follow; click a slot, block "Gym".
4. Study: flip a card, hit Missed, toggle Mistakes only.
5. Focus: start sprint, take off, land — arrival card + passport stamp.
6. Travel history: Month → Map — all blue routes together.

## Full feature inventory

**Home** — quote of the day (shuffle, auto-fit sizing), day-zero stats,
panic meter (live next-cutoff countdown), page cards, today digest
(due / study / reminders).

**Grades** — GPA 4.0 + % scales, weighted components, target sliders with
live "need X" badges (secured / pass / warn / fail), course CRUD, syllabus
import, overall KPI + insights.

**Deadlines** — course + urgency filters, live per-second countdowns, urgency
progress bars, submit checkboxes with confetti, `.ics` export, opt-in
browser notifications (2-hour window), clipboard status summary.

**Calendar** — month grid with event/deadline/study chips, agenda pane,
reminders CRUD, **day planner**: hourly timeline, click-to-block,
**drag blocks to reschedule**, overlap columns **+ clash warnings**,
pastel blocks, deadline/reminder/study markers, red now-line.

**Study** — syllabus → day-by-day battle plan on the timeline, streaks,
per-day completion, daily start+end times, seed plan; **flashcards**: topics from courses, custom
topics, symbols bar, big-view modal with keyboard nav, Got/Missed counts,
mistakes-only revise, edit inline.

**Finances** — monthly balance/income/expenses/saved %, budget bar, category
breakdown, transactions, recurring dues with one-click **Post overdue**,
wishlist that converts to expenses.

**Focus** — sprint timer with gradient ring, custom durations, rain/lo-fi/
white-noise mixer with volumes, mute-all; **airplane mode**: real routes,
cabins, aircraft, unlock tiers, departures board (2× next flight), live
Leaflet + offline canvas maps (Map/Follow that yields to your drags,
Day/Auto/Night, Labels toggle), comfort-blue night grade, engine hum,
crew bell, arrival celebration with city photos, **passport + travel
history** (week/month/year/all, blue-line route chains, totals, averages,
full route map).

**Notes** — notes/todos/trash tabs, rich text, image attach, reminders,
version history, drag reorder, due dates + priorities, `[[backlinks]]`
that jump between notes.

**Global** — command palette (`Ctrl/⌘+K`, 30+ commands; the only hotkey),
10 themes incl. color-vision-safe sets, JSON
backup export **+ import**, storage-full guard, screen-reader announcements,
`prefers-reduced-motion`, zero-dependency smoke tests (`npm test`).

## Hidden cross-links (mention one, sound smart)

- Finishing a flight records a focus sprint (Focus ↔ Flights).
- Study blocks and deadlines auto-appear on the calendar (Study/Deadlines → Calendar).
- Quote shuffle alternates faves vs the full pool.
- Every persist path warns instead of silently failing when storage is full.
